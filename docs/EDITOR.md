# 编辑器

## 统一编辑器

站点脚本、自定义区块、区块 CSS 使用同一个 `CodeEditor`：

- 行号
- 语法高亮
- 撤销/重做
- 符号快捷条
- 文件页签
- 保存

浮层顶部：

```text
‹ 返回     标题                保存
```

文件页签显示：

- `index.js`
- `index.html`
- `main.py`
- `style.css`

## 站点编辑器

- 多文件
- 入口文件 `★`
- 新建/重命名/复制/删除
- 语法检查
- 测试运行
- 配置参数
- 组件库
- 终端
- 自动保存

## 自定义区块编辑器

设置 → 主页布局 → 自定义区块：

- 右上角“编辑器”打开全屏编辑器
- 按内容自动选择 HTML/JS/PY 高亮
- 保存只关闭编辑器，回主页自定义浮层
- 不会触发“保存区块脚本”的返回目标

## CSS 编辑器

- 入口在输入框右下角
- 文件页签 `style.css`
- 自动加 `#home-custom-block` 作用域
- 保存后回浮层

## 自定义语法

设置 → 外观 → 自定义语法：

- 名称
- 扩展名
- 关键字 / 类型 / 常量 / 函数
- 行注释 / 块注释

保存后编辑器按扩展名自动应用，计数立即更新。

## 语法配色

设置 → 外观 → 语法配色：

- 预设色圆点
- 自定义颜色选择器
- 所有语言共用
- 修改立即生效

## 返回键

Android 返回键顺序：

```text
代码编辑器浮层 → 主页自定义浮层 → 页面栈 → 系统
```

不会在编辑器打开时直接退出 App。
