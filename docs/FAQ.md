# FAQ 与常见错误

## 文档

### 文档中心打不开 / 超时

- 文档在线读取；
- 网络不可用时会提示；
- 到 QQ 群 123456789 获取；
- 确认仓库公开：`https://github.com/qixidalao/World-Analysis`。

## 主页

### 自定义区块不显示

检查：

1. 模块顺序里是否有“自定义区块”；
2. 输入框不是空；
3. `js:` 代码是否 `return` 了字符串；
4. 日志里是否有 `js 区块失败`；
5. 保存后是否回到主页。

### 点击区块链接回不来

1.10.31 起外链交给系统浏览器，不再劫持 SPA。旧版本请升级。

### 自定义区块文字被按钮遮挡

1.10.33 起按钮移到输入框顶部工具栏，不再覆盖文字。

## 编辑器

### 编辑器保存后回到设置页

旧版本问题。1.10.35 起：

- 编辑器/CSS 保存只回浮层；
- 单选框只作用于“保存区块脚本”。

### 返回键退出 App

1.10.28 起系统返回优先关闭编辑器浮层。

## 语法高亮

### 自定义语法新增后显示 0 个

旧版本问题。1.10.19 起保存后自动刷新计数。

### 语法颜色在哪里改

设置 → 外观 → 语法配色，所有语言通用。

## 模块

### 模块安装失败，提示需要预编译

当前 ABI/Python 没有对应轮子；不会硬下源码。

### 安装后 import 失败

- 检查是否加载到当前会话；
- 重启 App 后需要重新加载；
- lean 包没有 Python。

### 搜索不到 PyPI 全库

搜索过滤的是当前商店目录，不是在线 PyPI 全库。

## 热修复

### 热修复显示 vN 但页面没变化

- CSS/JS 为空也会写版本标记；
- 检查日志 `rou.hotfix`；
- 验签失败会被拒绝。

## 网络

### 某些站点必须代理

- 设置 → 网络；
- 站点详情 → 网络覆盖；
- 代理认证字段当前只记录，主网络层不透传用户名密码。
