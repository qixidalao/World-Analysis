# 界析文档中心

界析是一个可编程 Android 解析客户端：站点规则、脚本、界面组件都在本地。

## 学习路径

1. [快速上手](QUICKSTART.md) — 安装、添加第一个站点、跑通解析
2. [用户手册](USER_GUIDE.md) — 主页、浏览、详情、播放、收藏、个人中心
3. [脚本 API](SCRIPT_API.md) — JS / 规则 / Python 的统一数据契约
4. [Python API](PYTHON_API.md) — 内置 CPython 与预编译模块
5. [规则 API](RULE_API.md) — CSS 选择器规则、分页、频道
6. [高级用法](ADVANCED.md) — 多文件、动态 import、缓存、代理、热修复
7. [扩展包](PLUGINS.md) — 语法、组件、主题、页面、布局
8. [界面自定义](CUSTOMIZE.md) — 主页区块、JS/PY 区块、CSS、语法配色
9. [模块商店](MODULES.md) — 搜索、安装、来源、依赖、加载
10. [终端](TERMINAL.md) — shell、Python、JS、文件面板
11. [热修复与更新](HOTFIX_UPDATE.md) — 签名、灰度、回滚、APK 更新
12. [安全模型](SECURITY.md) — 哪些是隔离，哪些不是
13. [FAQ](FAQ.md) — 常见问题
14. [构建](BUILD.md) — 手工构建、签名、三 ABI
15. [发布记录](RELEASE.md) — 当前版本与校验值

## 文档原则

- 以当前 APK 的实际行为为准；
- 不把“计划中的功能”写成已完成；
- 示例使用 `example.com`，不依赖任何具体站点；
- 涉及风险的地方直接写清楚，不用“安全”两个字模糊带过。
