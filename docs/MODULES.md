# 模块商店

## 分类

- 我的商店（开发者商店）
- 官方 PyPI 纯 Python
- 第三方商店
- 已安装
- 反馈

## 搜索

每个分类顶部有搜索框，按模块名和说明过滤当前目录。

注意：搜索的是已加载的商店目录，不是在线 PyPI 全库检索。

## 安装

- 纯 Python 模块直接安装；
- 预编译模块要求匹配 ABI 和 Python 版本；
- 没有适配轮子时提示“需要预编译轮子，当前不下载安装”；
- 安装成功后自动加载到当前 Python 会话。

## 已安装

分两组：

- 直接安装
- 依赖

每个模块显示：

- 来源：开发者商店 / 第三方商店 / PyPI 官方 / 依赖
- 版本
- 路径
- 是否在会话中
- 可更新版本

## 加载是什么意思

- 安装：把包写到磁盘；
- 加载：把包加入当前 Python 会话 `sys.path`，脚本 `import` 立即可用；
- 本版安装成功后自动加载；
- 重启 App 后需要重新加载。

预编译模块是原生 `.so`，必须匹配：

- ABI：arm64-v8a / x86_64；
- Python：3.14。

## 来源校验

当前模块目录可以声明来源和 SHA-256，但安装器还没有强制校验 wheel 哈希/签名；预编译模块仍应只从可信商店安装。

## 卸载

从“已安装”点卸载；依赖不会自动级联删除，避免误删共享依赖。

## 反馈

已安装模块缺轮子、需要新预编译模块，用“反馈”提交；也可到 QQ 群 123456789。
