# 界面与导航

## 底部 Tab

```text
主页 / 浏览 / 收藏 / 个人中心
```

“个人中心”只放个人信息：

- 资料卡
- 收藏
- 历史
- 反馈与建议

不再放外观、布局、播放等设置。

## 主页

- 顶部：站点选择、调色板
- 模块：欢迎语、功能卡、我的站点、继续观看、公告、自定义区块
- 调色板 → 主页自定义：
  - 模块开关/顺序
  - 轮播高度、卡片列数
  - 欢迎语标题/正文
  - 自定义区块
  - 背景图

## 设置

| 分组 | 内容 |
|---|---|
| 偏好 | 站点与脚本、网络、浏览缓存、播放、外观、主页布局 |
| 运行时 | Python、扩展包、存储、关于 |
| 关于 | 文档中心、检查更新、开源许可、反馈 |

## 浏览

- 站点切换只在启用站点里选
- 缓存默认 30 分钟
- 顶部频道/搜索/刷新/脚本管理
- 下拉强制刷新

## 详情

- 视频/图片/音频/小说统一详情
- 组件块可扩展
- 相关视频卡片带 site，不跨站点串解析

## 个人中心

- 资料卡点击编辑
- 收藏/历史
- 反馈页

## 文档

设置 → 关于 → 文档中心。

在线读取，失败提示 QQ 群 123456789。

## 返回

- 系统返回优先关浮层/编辑器
- 页面栈为空回主页
- 主页再返回：Toast「再按一次退出」
