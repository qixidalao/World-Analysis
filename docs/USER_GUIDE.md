# 用户手册

## 主页

主页由模块组成：

- 欢迎语
- 功能卡
- 我的站点
- 继续观看
- 公告
- 自定义区块

右上角调色板可打开“主页自定义”：

- 模块开关
- 模块顺序
- 轮播高度、卡片列数
- 欢迎语标题/正文
- 自定义区块
- 背景图

个人中心不再放外观/布局；这些在设置里。

## 站点切换

- 主页顶部显示当前站点；
- 顶部站点选择器只列出启用站点；
- 禁用站点仍显示在“我的站点”，标“已停用”；
- 默认站点在设置 → 站点与脚本里设置；
- 启动顺序：默认站点 → 最近站点 → 第一个启用站点。

## 浏览

- 主页内容默认缓存 30 分钟；
- 设置 → 浏览缓存可调 0–1440 分钟；
- 0 表示不缓存；
- 支持 `site.tabs` 自定义频道；
- 列表支持自动翻页。

## 搜索

搜索页使用站点脚本的 `search(keyword)` 返回地址，再走统一解析。

脚本没有 `search` 时，搜索会提示当前站点不支持。

## 详情

脚本返回：

```js
{
  type: 'detail',
  detail: {
    title, pic, desc,
    play, eps, tags, blocks
  }
}
```

媒体类型：

- `video`
- `image / images`
- `audio`
- `novel / book`

## 播放

- WebView + hls.js；
- HLS 分片缓存到 IndexedDB，按设置里的上限做 LRU；
- 支持手势亮度/音量/进度；
- 支持横屏；
- 后台播放、硬解开关仍是记录项，不是真实系统能力。

## 收藏 / 历史

- 收藏和历史的卡片带站点标识；
- 跨站点打开详情不会串解析器；
- 历史保留进度；
- 长按可删除单条。

## 个人中心

只放个人信息相关内容：

- 资料卡
- 收藏
- 历史
- 反馈与建议

外观、布局、播放、存储、关于都在设置。

## 设置

| 分组 | 内容 |
|---|---|
| 偏好 | 站点与脚本、网络、浏览缓存、播放、外观、主页布局 |
| 运行时 | Python、扩展包、存储、关于 |
| 文档 | 关于 → 文档中心 |

## 日志

- 内存 500 条 + 落盘 400 条，合并去重；
- 可只看错误；
- 支持单条长按复制；
- 支持多选、全选、复制选中；
- 清理会同时清内存和落盘。

## 存储

- 统计 localStorage；
- 另显示 WebView/IndexedDB 总占用；
- 可清理图片、视频、页面缓存；
- 已装包和 HLS 分片不计入 localStorage 统计。
